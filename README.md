# УниПланер

Веб-приложение для студентов КФУ: расписание пар, свои дела, анонсы мероприятий университета и ИИ-ассистент, который помогает вписать дела в учебную неделю. Например, на запрос «Хочу сходить в спортзал» ассистент смотрит расписание и предлагает свободные окна.

Проект создан на хакатоне «Идея. Код. Релиз» (IT-сообщество МГУ Viribus Unitis, Москва, 19–20 апреля 2025).

## Возможности

- **Расписание недели:** пары разбираются из HTML-страницы расписания КФУ (BeautifulSoup) или загружаются из JSON; к ним можно добавлять свои события.
- **ИИ-ассистент:** запрос студента и его расписание отправляются в Gemini, ответ — варианты времени с пояснениями.
- **Анонсы КФУ:** лента мероприятий с media.kpfu.ru.
- **Аккаунты:** регистрация и вход, пароли хешируются bcrypt, доступ по JWT.

## Стек

React 19, React Router · FastAPI, SQLAlchemy, MySQL · Gemini API · Docker Compose, nginx.

## Запуск

```bash
cp .env.example .env      # вписать GEMINI_API_KEY и JWT_SECRET
docker compose up --build
```

- приложение: http://localhost:3001
- API: http://localhost:8000
